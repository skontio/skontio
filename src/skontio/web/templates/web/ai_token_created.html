Claude Desktop und andere stdio-Clients

skontio-mcp.py herunterladen (braucht nur Python 3) und in claude_desktop_config.json eintragen:

{
  "mcpServers": {
    "skontio": {
      "command": "python3",
      "args": ["/Pfad/zu/skontio-mcp.py"],
      "env": {"SKONTIO_URL": "{{ public_url }}", "SKONTIO_TOKEN": "{{ raw }}"}
    }
  }
}

Erreichbar nur im Heimnetz oder per VPN (Caddy lässt /mcp nur aus privaten Netzen zu). Wer Skontio als Python-Paket installiert hat, kann statt python3 …/skontio-mcp.py auch den Befehl skontio-mcp verwenden.
